Welcome to the help page for Join. This page will explain how the project management functions are used.

What is Join?

Join is a kanban-based project management tool for organizing tasks, contacts and project progress.

How to use it

  1. Board: View and organize project tasks.
  2. Contacts: Manage contacts for assignments.
  3. Add Task: Create new tasks and subtasks.
  4. Moving Cards: Change the status of tasks.
